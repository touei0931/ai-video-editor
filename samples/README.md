# テスト素材

## 🔴 方針: 実素材はリポジトリに置かない

**友達が映っている動画は、private リポジトリであっても GitHub に置かない。**（2026-08-18 決定）

代わりに **ffmpeg で合成した素材**を使う。

```bash
python scripts/make_test_media.py
```

生成物は `.gitignore` 済みなので、リポジトリには入らない。Git LFS も使わない。

## 合成素材のほうが回帰テストには向いている

これは妥協ではなく、テスト設計としてこちらが正しい。

| | 実素材 | 合成素材 |
|---|---|---|
| 決定論性 | 同じ入力→同じ出力だが、素材ごとに期待値を手で書く必要がある | **無音区間の位置が既知**なので期待値を厳密に書ける |
| 権利・プライバシー | 🔴 顔・声が入る。同意が必要 | 問題なし |
| リポジトリ容量 | 数十 MB（LFS 必要） | **0**（生成するので commit しない） |
| CI での再現性 | ファイルが壊れると気づきにくい | スクリプトから毎回作り直す |

## 生成される3本

| ファイル | 内容 | 何の検証に使うか |
|---|---|---|
| `sample_portrait_solo.mp4` | 縦 1080×1920・30秒・モノラル | 縦素材のクロップ不要パス |
| `sample_landscape_solo.mp4` | 横 1920×1080・30秒・モノラル | 横→縦の 9:16 クロップ |
| `sample_landscape_duo.mp4` | 横 1920×1080・30秒・**話者A/Bを左右chに分離** | 話者切り替えロジックの形の確認 |

映像は `testsrc2`（フレーム番号が焼き込まれるので、カット位置のズレが目視でも分かる）。
音声は既知の区間だけ通したサイン波。**発話区間の定義は `scripts/make_test_media.py` の
`SPEECH_SOLO` / `SPEECH_DUO_A` / `SPEECH_DUO_B` にあり、テストの期待値はここから直接書ける。**

## 🔴 合成素材で検証**できない**こと

ここは正直に区別しておく。以下は合成素材では確認できないので、**ローカルの実素材でしか検証できない**。

| 項目 | 理由 | どこで検証するか |
|---|---|---|
| **文字起こしの精度（CER）** | サイン波に言葉がない | ローカル実素材 + 友達の実機（T6） |
| **フィラー・言い直しの検出** | 同上 | 同上 |
| **顔検出・話者アクティブ判定** | 顔が映っていない | 同上 |
| **感情・韻律によるテロップ出し分け** | 実際の話し方がない | 同上 |
| **VFR 素材の CFR 正規化** | 合成は CFR になる | スマホ実撮影の素材が必要 |

合成素材で検証できるのは「**パイプラインが完走するか**」「**無音検出とカットの座標計算が正しいか**」
「**テロップ描画と書き出しの回帰**」まで。ここまでを CI が守り、精度は実機で見る、という分担にする。

## ローカルに実素材を置く場合

`fixtures-local/` に置く（`.gitignore` 済み。**このディレクトリは絶対に commit しない**）。

```
fixtures-local/
├── real_solo.mp4      # 一人・実撮影
└── real_duo.mp4       # 複数人・実撮影
```

友達から素材を受け取る場合も、**GitHub には上げず手元だけで使う**。
共有が必要なら、リポジトリではなく別の手段（ローカル転送）を使うこと。
