# テスト素材（Phase 0 T0）

CI のスモークテストと golden file テストで使う素材をここに置く。
`.gitattributes` で **Git LFS 管理**にしてある（`samples/**/*.mp4` など）。

## 必要な3本

友達に撮ってもらうか、similar な既存素材から30秒を切り出す。

| ファイル名 | 内容 | 何の検証に使うか |
|---|---|---|
| `sample_portrait_solo.mp4` | **縦(9:16)・一人**・30秒 | 縦素材のクロップ不要パス、①カット、②テロップ |
| `sample_landscape_solo.mp4` | **横(16:9)・一人**・30秒 | 横→縦の 9:16 自動クロップ、③ズーム |
| `sample_landscape_duo.mp4` | **横(16:9)・二人の会話**・30秒 | **話者アクティブ判定**（Phase 3 の最大の技術リスク） |

## 素材の条件

- 30秒程度（CI で毎PR回すので長いと遅い）
- **無音区間とフィラー（「えー」「あの」）が数回入っていること** — ①の検証に必要
- 1080p / 30fps 前後。スマホ撮影の **VFR（可変フレームレート）素材をあえて1本混ぜる**と、
  CFR 正規化の検証になる（§15.2 の落とし穴）
- `sample_landscape_duo.mp4` は**掛け合いがあること**（交互に話す、かぶる箇所がある）

## 追加方法

```bash
git lfs track "samples/**/*.mp4"
git add samples/sample_portrait_solo.mp4
git commit -m "test: 縦・一人のテスト素材を追加"
```

> ⚠ 実際の配信素材をそのまま入れないこと。**private リポジトリだが、
> 友達の顔が映る素材を GitHub に置いてよいか事前に確認する。**
> 懸念があれば LFS ではなくローカル配置（`.gitignore` 済み）にして、
> CI では合成素材（ffmpeg の `testsrc` + 読み上げ音声）を使う方針に切り替える。
