# PAC（Final Cut Pro プラグイン・動作テスト版）

Final Cut Pro の**画面の中に PAC のパネルを出せるか**を確かめるためのテスト版です。
5分くらいで終わります。まだ実際のカットや文字起こしはできません（画面だけ入っています）。

## やること

1. `PAC-fcp-test.zip` と `インストールと確認.command` を、同じフォルダ（デスクトップなど）に置く
2. `インストールと確認.command` を **右クリック → 開く**
   - 「開発元を確認できません」と出たら、もう一度 **右クリック → 開く** → 「開く」を押す
   - （普通のダブルクリックだと macOS に止められます）
3. 黒い画面が流れて、最後に「終わりました」と出たら閉じてOK
4. **Final Cut Pro を起動**する
5. 上のメニューの **「ウィンドウ」→「エクステンション」** を開く
6. そこに **「PAC」** があるか見る

## 見てほしいこと

「PAC」を押すとパネルが開きます。**開いたら、次の4つを見て教えてください。**

1. 上に「カット」「テロップ」の切り替えボタンが出ているか
2. 「カット」画面に、暗いグレーのタイムラインが出ているか
3. 「テロップ」画面に切り替えると、右側に設定（フォント・大きさ・色）が出るか
4. **文字が豆腐（□）になっていないか** — 日本語がちゃんと表示されているか

パネルの画面を**撮影して送ってください**。真っ白／真っ黒でも、それが分かれば十分です。

## うまくいかないとき

そのまま報告してもらえれば大丈夫です。どれも想定内です。

- 「壊れているため開けません」と出る
- 「ウィンドウ > エクステンション」に PAC が出てこない
- パネルは開くが中身が真っ白

## 最後に

デスクトップにできた **`PAC診断結果.txt`** を送ってください。
何が起きたかがこの中に記録されています。

## アンインストール

アプリケーションフォルダの `PAC.app` をゴミ箱に入れるだけです。
