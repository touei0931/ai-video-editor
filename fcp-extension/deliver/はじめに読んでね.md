# PAC（Final Cut Pro プラグイン・動作テスト版）

まだ機能はありません。**「Final Cut Pro の中に PAC のパネルが出せるかどうか」だけを確かめる**ためのテスト版です。
5分くらいで終わります。

## やること

1. `PAC-fcp-test.zip` と `インストールと確認.command` を、同じフォルダ（デスクトップなど）に置く
2. `インストールと確認.command` を **右クリック → 開く**
   - 「開発元を確認できません」と出たら、もう一度 **右クリック → 開く** → 「開く」を押す
   - （普通のダブルクリックだと macOS に止められます）
3. 黒い画面が流れて、最後に「終わりました」と出たら閉じてOK
4. **Final Cut Pro を起動**する
5. 上のメニューの **「ウィンドウ」→「エクステンション」** を開く
6. そこに **「PAC」** があるか見る
   - **あった場合** → 押して、出てきたパネルの画面を撮影して送ってください 🎉
   - **なかった場合** → その旨を伝えてください（それも大事な結果です）
7. デスクトップにできた **`PAC診断結果.txt`** を送ってください

## うまくいかないとき

- 「壊れているため開けません」→ 想定内です。そのまま報告してください
- エクステンションのメニュー自体が無い → FCP のバージョンを教えてください

## アンインストール

アプリケーションフォルダの `PAC.app` をゴミ箱に入れるだけです。
