# 素材を並べる画面（メインのタイムライン）

Final Cut の代わりに使える編集ソフトにするための土台。
2026-08-27 に作り直した。

## 何がどこにあるか

| 場所 | 役目 |
|---|---|
| `src/timeline/project.ts` | 中身（素材・レーン・クリップ・テロップ）と、その上での操作。**画面も React も知らない** |
| `src/timeline/TimelineScreen.tsx` | メインの編集画面 |
| `src/timeline/Viewer.tsx` | プレビュー |
| `src/timeline/useTimelinePlayer.ts` | 並べたクリップを1本の動画のように再生する |
| `src/timeline/probe.ts` | 選んだファイルを素材にする（長さと画の有無を読む） |
| `src/timeline/fcpxml.ts` | Final Cut の XML を組み立てる |
| `src/timeline/persist.ts` | 保存と読み込み（読み込んだ中身は必ず確かめる） |
| `src/timeline/PacEditor.tsx` | 入れ物。メインと、下ごしらえの子画面を切り替える |

計算の部分は Node からそのまま呼べる。テストは
`npm run test:timeline` / `test:tlxml` / `test:tlsave`。

## 考え方

### 自動カットは子画面だけ

PAC の売りである自動カット・自動テロップは、**取り込みの子画面に集約**した。
メインは Final Cut と同じ道具（分ける・伸縮・移動・詰める）しか持たない。

混ぜると、「素材を並べる」と「1本の素材を詰める」の2つの考え方が
同居して、どちらの操作なのか分からない画面になる。

子画面が返すのは3つだけ。

```
素材 ／ 残す区間（素材の中の時刻） ／ テロップ（素材の中の時刻）
```

残す区間1つが、クリップ1つになる。1本の長いクリップにして
「切る所」を別に覚えておく形にはしない。取り込んだ後に手で編集した瞬間、
タイムラインの見た目と切る所の指定が食い違うため。

### 時刻は「素材の中の時刻」で持つ

保存するものは全部、素材の中の時刻。タイムライン上の位置は
毎回 `layout()` で計算して出す。

位置を保存すると、前のクリップを1つ縮めただけで後ろ全部を
書き換えることになる。

テロップも素材に結び付けてある。おかげで、クリップを動かしても・分けても・
端を縮めても・同じ素材を2回使っても、テロップが自動で付いてくる。
端の外に出た分は切り詰められる（切った言葉の字幕が次のクリップに残らない）。

### 詰める（マグネティック）

メインレーンの並び順は **clips の配列の順**が正。詰めるが入っているとき、
位置は前から順に足して決まる。位置から順番を決めると、同じ位置に
2つ来たときに順番が揺れる。

穴を空けたいときは「空き」というクリップを置く。詰める設定を切って
逃げてはいけない（一度押しただけで、二度と詰まらなくなる）。

## 踏んだ罠

- **ref の入れ替えは元に戻る** — プレビューは `<video>` を2枚使って
  境目で入れ替えるが、`ref.current` を入れ替える書き方では、
  React が描画のたびに入れ直すので効かない。「どちらを表にするか」の旗で行う。
- **時計を映像に合わせない** — `video.currentTime` を時計にすると、
  入れ替えた瞬間に「次のクリップの素材内の時刻」へ飛ぶ。時計は自前で持ち、
  ずれたら**映像側**を直す。
- **止まっていた間の差をそのまま足さない** — 別のアプリに切り替えている間
  `requestAnimationFrame` は止まる。戻ってきた1フレーム目の差は
  離れていた時間まるごとなので、足すと再生位置が数十秒先へ飛ぶ。
- **flex はボタンを潰す** — 伸び縮みする隙間が幅を取ると、日本語のラベルが
  1文字ずつ縦に折り返される（幅46px・高さ201px になった）。
  `flex: 0 0 auto` と `white-space: nowrap` を必ず付ける。
- **持ち込まれた `grid-area`** — `shell.css` の `.fcp-timeline` は
  別の格子に置かれる前提の `grid-area` を持っている。他の格子へ入れると
  余計な行が生まれ、指定した 160px の行があるのに 40px しか出ない。

## まだ無いもの

- **動画としての書き出し** — Final Cut の XML は出せるが、複数素材を
  繋いだ動画そのものは書き出せない。サイドカー（Python）側の作り直しが要る。
- **レーンの並べ替え・名前の変更**
- **音量とフェード**
