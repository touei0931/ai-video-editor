# はじめての使い方

Mac にアプリを入れて、動画を1本編集するまでの手順です。

---

## 1. アプリを入れる

1. 受け取った `AI動画編集-1.0.0-arm64.dmg` をダブルクリックします
2. 開いた窓の中で、アプリのアイコンを **Applications** のフォルダへドラッグします

## 2. 初回だけ、開き方が違います

このアプリは Apple の審査を通していないので、普通にダブルクリックすると

> 開発元を確認できないため開けません

と出ます。**壊れているわけではありません。** 次のようにすると開けます。

1. アプリケーションフォルダで、**AI動画編集** を右クリック（または control を押しながらクリック）
2. 出てきたメニューの **「開く」** を選ぶ
3. 同じ警告が出るので、そこにある **「開く」** を押す

**2回目からは普通にダブルクリックで開けます。**

macOS のバージョンによっては、代わりに
「システム設定 → プライバシーとセキュリティ」の下のほうに
「"AI動画編集" は開発元を確認できないため…」という行が出ることがあります。
その場合は横の **「このまま開く」** を押してください。

## 3. 動画を選ぶ

1. アプリを開いて **「動画を選ぶ」** を押します
2. 編集したい動画を選びます

**動画のあるフォルダへのアクセスを聞かれたら、許可してください。**
編集の途中経過を、その動画の隣に保存するために使います。

選んだあと、解析が始まります。

- 10分の動画で **6〜12分** くらいかかります
- 「あと約○分」が画面に出ます
- **電源につないだままにしてください**（ファンの無い機種なので、熱くなると遅くなります）
- 他のアプリを使っていても構いません

## 4. カットを決める

無音・「えー」「あの」・言い直しを、AIが自動で見つけます。

画面には**カットしたときの繋がり方**が繰り返し再生されます。
そこが不自然でなければ **「ここを切る」**、残したければ **「ここは残す」** を押します。

- キーボードの **Y**（切る）／**N**（残す）でも同じことができます。慣れるとこちらが速いです
- 迷ったら **「あとで見る」**。あとでまとめて見直せます
- **「残りを全部切る」** を押すと、残りをまとめて処理して先へ進めます

### 切りすぎ・足りないと感じたら

画面の上にある **「間の詰め具合」** を変えると、候補を作り直します。

| | どうなるか |
|---|---|
| ゆったり | 間を大きく残す。落ち着いた話し方向け |
| ふつう | 標準 |
| テンポよく | よく詰まる |
| とにかく詰める | 間がほとんど残らない |

**作り直しても、解析はやり直しません**（数秒で終わります）。
ただし、それまでに押した「切る／残す」はやり直しになります。

## 5. 自動で決めた分を確かめる

カットが決まると「自動で決めたカット」が出ます。
**「通しで確認する」** を押すと、切った状態で通して再生します。

- **赤い縦線** … 切った位置
- **青い帯** … 残してある候補

**印を押すと、その場で切る／戻すが切り替わります。** 押すとその少し手前から流し直すので、
戻した結果どう聞こえるかがすぐ分かります。

### 要らない場面を丸ごと切る

無音でもフィラーでもない箇所（脱線、失敗、雑音）も切れます。

1. 切りたいところの手前で一時停止して **「ここから」**
2. 終わりのところで **「ここまで」**
3. **「○秒を切る」** を押す

キーボードなら **I**（ここから）**O**（ここまで）**Enter**（切る）です。
選び直したいときは **Esc** で取り消せます。

この画面を閉じるのは、右上の **「確認を終える」** を押したときだけです。
キーを押して閉じてしまうことはありません。

## 6. テロップを直す

文字起こしからテロップを作ります。**赤く出ているものだけ**見れば足りるように作ってあります。

- **E** で文言を直す
- **1 〜 9** で雛形（通常・補足・強調と、足した枠）を切り替える
- プレビューの文字を**ドラッグ**すると位置を動かせます
- 全体の色や大きさは、右の「雛形を編集」で一度に変えられます

### 音がうるさいとき

テロップを選ぶたびに、その2.5秒前から繰り返し再生します。
声を聞かないと文言が合っているか分からないので、既定ではこうしています。

ただ、何百枚も流し読みするときは音が邪魔です。プレビューの下に2つボタンがあります。

| | |
|---|---|
| 🔈 音あり / 🔇 音を消している | プレビューの音を消します |
| ▶ 選ぶと再生 / ⏸ 自動では再生しない | テロップを選んだときに自動で再生するかどうか |

**どちらも次に開いたときも覚えています。**
自動再生を切っていても、聞きたいときは **Space** か **「頭から再生」** で鳴らせます。

### 書体（フォント）を変える

「雛形を編集」の **書体** から選びます。ボタン自体がその書体で出ているので、
押す前に雰囲気が分かります。

| | どんな字 |
|---|---|
| ゴシック体 | 標準。太くてはっきり読める |
| 丸ゴシック体 | 角が丸い。やわらかい印象 |
| 明朝体 | 縦横に太さの差がある。落ち着いた印象 |
| インパクト | 極太の見出し用。短い言葉向け |

**太字** と **斜体** も同じ行にあります。

- 太字は、**その書体の太いほうの字に切り替わります**（無理に太らせているのではありません）。
  ただし「インパクト」だけは太さが1種類しか無いので、字を太らせて作ります。
- 斜体は字を傾けて作ります。日本語の書体に斜体は元々無いので、これはどのソフトでも同じです。

書体を変えると**改行の位置も計算し直します**。書体によって字の幅が違うためです。

### 雛形の枠を増やす

はじめは **通常・補足・強調** の3つです。「オノマトペ用」「引用用」のように
**自分の枠を足せます**（全部で9つまで）。

1. 「雛形を編集」の右の **「＋ 枠を足す」** を押す
2. すぐ下の **「枠の名前」** に名前を書く（例: オノマトペ）
3. 書体・色・大きさを決める

あとは、その見た目にしたいテロップを選んで **数字キー** を押すだけです。
数字は左から順（通常=1、補足=2、強調=3、足した枠=4、5…）。

通常・補足・強調の3つは、文字起こしから自動で割り当てられる枠なので消せません
（名前は変えられます）。足した枠を消すと、その枠を使っていたテロップは通常に戻ります。

### 見た目に名前を付けて覚えておく

雛形をひととおり決めたら、**「＋ 今の見た目を保存」** を押して名前を付けてください。
例えば「普段用」「商品紹介用」のように、**何組でも持てます**（12組まで）。

- **次に別の動画を編集するとき、最後に使った組の見た目で始まります**
- 一覧の名前を押すと、その見た目が**今の動画にも当たります**
- 同じ名前で保存すると上書きです
- 覚えるのは色・書体・太さ・大きさ・位置・枠の構成で、テロップの文言は覚えません

**「最初の見た目に戻す」** は、今の動画の雛形をアプリ最初の状態に戻します。
**保存した見た目は消えません。**

### 改行の位置を変えたいとき

長いテロップは、**言葉の切れ目**で自動的に改行されます。
行の長さがなるべく揃うように分けるので、たいていはそのままで問題ありません。

変えたいときは **「改行位置」** の欄を使います。
文と文のあいだにある小さな **`·`** を押すと、そこで改行されます（**`↵`** に変わります）。
もう一度押すと元に戻ります。全部やめたいときは **「自動に戻す」** です。

**文字の大きさを変えると、改行も自動でやり直します。**
小さくすれば1行に収まることもありますし、大きくすれば行が増えます。
はみ出しそうなときは、少しだけ縮めて収めます（「収めるため ○% に縮小」と出ます）。

### テロップが重なるとき

前のテロップがまだ出ている間に次のテロップの番が来たら、
**前を切り上げて、次を予定どおりの時刻に出します**。
声より遅れてテロップが出ることはありません。

そのため、次のテロップに接しているところで「長く」を押しても伸びません
（「次のテロップが始まるまで出ています」と出ます）。

### 書き出し方の選択

画面の上に3つのチェックがあります。

| | 何が出るか |
|---|---|
| 動画に文字を入れる | テロップを焼き込んだ動画 |
| 字幕ファイルも作る | `.srt`（他の編集ソフトで読める字幕） |
| Final Cut 用も作る | `.fcpxml`（**カットした状態のタイムライン**） |

**Final Cut で仕上げたい場合**は、3つ目にチェックを入れてください。
Final Cut の「ファイル → 読み込む → XML…」から開くと、
カットが入った状態のタイムラインになります。
テロップの**書体・色・大きさ・位置もそのまま入ります**。
そこから BGM を足したり、テロップを直したりできます。

#### 初回だけ、フォントを入れてください

このアプリのフォントは**アプリの中にしか入っていません**。
そのままだと、Final Cut は書体だけ別のもの（ヒラギノなど）に置き換えて開きます。
警告は出ません。

書き出したファイルの隣に **「〜_フォント」** というフォルダができています。

1. そのフォルダを開く
2. 中の **.ttf ファイルをすべて選んで**ダブルクリック
3. 出てきた窓の **「インストール」** を押す（Font Book が開きます）

**入れるのは最初の1回だけです。** 次の動画からは何もしなくて構いません。
色・大きさ・位置は、フォントを入れなくても合います。

## 7. 通しで確認して書き出す

**「通しで確認 →」** を押すと、テロップと人物アップを乗せた状態で通して再生します。
問題なければ **「書き出す」** を押します。

書き出しには 10分の動画で **3〜8分** くらいかかります。
進み具合と残り時間が出ます。途中でやめることもできます。

---

## 困ったとき

### 途中でやめたい

**「編集をやめる」** を押すと、下書きを保存するか聞かれます。
保存しておけば、次に同じ動画を開いたとき**続きから始められます**（解析もやり直しません）。

アプリの最初の画面にも「途中の編集を続ける」として並びます。

### 「この動画は編集できません」と出た

声が入っていない動画です。このアプリは話している内容をもとに編集するので、
声が入っていないと何もできません。

### エラーが出た

メニューの **「ヘルプ → 不具合の記録を開く」** を押すと、
記録のあるフォルダが開きます。その中の `last-error.json` を送ってください。

### 動作が重い

- 電源につないでください
- 他のアプリを閉じてください
- 20分を超える動画は時間がかかります。まずは10分くらいで試してください

### キーボード操作を忘れた

**F1** を押すと一覧が出ます。
