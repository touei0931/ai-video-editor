# PAC — はじめての使い方

**PAC**（Prep Auto Cut）は、喋り主体の動画の**下ごしらえ**をするアプリです。
カット・テロップ・人物アップの案を自動で作るので、あとは確認して書き出すか、
Final Cut Pro に渡して仕上げます。

Mac にアプリを入れて、動画を1本編集するまでの手順です。

---

## 1. アプリを入れる

1. 受け取った `PAC-….dmg` をダブルクリックします（`…` はバージョン番号）
2. 開いた窓の中で、アプリのアイコンを **Applications** のフォルダへドラッグします

## 2. 初回だけ、開き方が違います

このアプリは Apple の審査（公証）を通していないので、普通にダブルクリックすると警告が出ます。
**壊れているわけではありません。** 出る文言は2種類あります。

### A. 「開発元を確認できないため開けません」と出たとき

1. アプリケーションフォルダで、**PAC** を右クリック（または control を押しながらクリック）
2. 出てきたメニューの **「開く」** を選ぶ
3. 同じ警告が出るので、そこにある **「開く」** を押す

**2回目からは普通にダブルクリックで開けます。**

macOS のバージョンによっては、代わりに
「システム設定 → プライバシーとセキュリティ」の下のほうに
「"PAC" は開発元を確認できないため…」という行が出ることがあります。
その場合は横の **「このまま開く」** を押してください。

### B. 「"PAC" は壊れているため開けません」と出たとき

**捨てないでください。壊れていません。**
インターネット経由で受け取ったファイルに macOS が付ける印が残っているだけです。
上の右クリックでは消えないので、次のようにします。

1. **Launchpad → その他 → ターミナル** を開きます（`command + スペース` で `ターミナル` と打っても出ます）
2. 出てきた黒い（または白い）窓に、**次の1行をそのまま貼り付けて** `return` を押します

```
xattr -cr /Applications/PAC.app
```

3. パスワードを聞かれたら、Mac のログインパスワードを入れます
   （**打っても画面に何も出ませんが、入力はできています**。そのまま `return`）
4. 何も表示されずに次の行が出たら成功です。ターミナルは閉じて構いません
5. **PAC** をダブルクリックします

**これも最初の1回だけです。**

## 3. 動画を選ぶ

1. アプリを開いて **「動画を選ぶ」** を押します
2. 編集したい動画を選びます

**動画のあるフォルダへのアクセスを聞かれたら、許可してください。**
編集の途中経過を、その動画の隣に保存するために使います。

選んだあと、解析が始まります。

> **1本目だけ、待ち時間が増えます。**
> 声を文字にするための部品（約1.6GB）を、最初の1回だけインターネットから取ってきます。
> **Wi-Fi につないだまま**にしてください。回線によっては、これだけで10〜30分かかります。
> **2本目からは、この待ち時間はありません。**

- 10分の動画で **6〜12分** くらいかかります
- 「あと約○分」が画面に出ます
- **電源につないだままにしてください**（ファンの無い機種なので、熱くなると遅くなります）
- 他のアプリを使っていても構いません

## 4. 画面の見かた（カットもテロップも同じ形）

編集ソフトと同じ並びです。どの工程でもこの形は変わりません。

```
┌───────────────────────────┬──────────┐
│                           │          │
│          映  像           │  選んだ  │
│                           │  ところ  │
├───────────────────────────┤  の詳細  │
│  ▶  再生・音量・速度       │          │
├───────────────────────────┴──────────┤
│  タイムライン（下の帯）               │
│    素材 … 映像のコマ。切る所が暗くなる │
│    音   … 声の波                      │
└──────────────────────────────────────┘
```

**白い縦線**がいまの再生位置です。線をドラッグすると動かせます。
目盛りを押しても、その場所へ飛びます。

| したいこと | やり方 |
|---|---|
| 横に動かす | **何もない所をドラッグ**（スクロールバーを掴まなくて構いません） |
| 拡大・縮小 | 右上の **＋ / −**、または **Ctrl（⌘）を押しながらホイール** |
| 全体を見る | **全体** |
| 再生位置を見失った | **白線へ** |
| パネルの幅・高さ | 境目をドラッグ |
| コマを大きく / 小さく | **1** / **2**（テロップ画面を除く） |

> **拡大したまま再生すると、白線は画面の端まで来たところで先へ送られます。**
> 自分で別の場所へ動かした場合は、そこから勝手に戻りません。
> 戻りたいときは **白線へ** を押してください。

## 5. カットを決める

無音・「えー」「あの」・言い直しを、AIが自動で見つけます。
**素材のコマの上に直接**重なって出るので、「この絵のところを切る」がそのまま見えます。

| 見え方 | 意味 |
|---|---|
| **暗くなっている（赤い枠）** | 切る |
| そのまま | 残す |
| **少し暗い（紫の枠）** | 保留（まだ決めていない） |

暗い所を押すと選ばれ、右側にその中身（何を切るのか、前後のことば、AIの見立て）が出ます。
右上の **カット判定** に、切る箇所・切る秒数・保留の数が出ます。

### 決める

| キー | |
|---|---|
| **D** | 切る |
| **F** | 残す |
| **G** | 保留 |
| **↓ / ↑** | 次 / 前の**保留**へ移る |
| **Q** | 白線より**前**を、頭からまとめて切る |
| **W** | 白線より**後ろ**を、末尾までまとめて切る |

**↓ を押すと、その保留の少し手前から再生します。**
繋がりを聞いて D か F を押す、の繰り返しで片づきます。
保留が無くなると「保留はもうありません」と出ます。

右側の **切る / 残す / 保留** のボタンでも同じことができます。

### 切る範囲を伸ばす・縮める

帯の**端をドラッグ**します。1コマ単位で合わせたいときは右側の **−1f / +1f**。

- 隣のカットの切れ目に**吸い付き**ます。切りたくないときは **N** で吸着を切ります
- **Shift** を押しながらだと、吸着もコマの丸めも外れます
- 動かした量は掴んでいる間、その場に「+3f 移動」のように出ます

### カット［表示 / 非表示］

タイムラインの左上で切り替えます。

| | 何が見えるか |
|---|---|
| **表示** | 切る所を**暗くして**、元の長さのまま見せます。再生も飛ばしません |
| **非表示** | 切る所を**詰めて**、出来上がりの長さで見せます。再生も飛ばします |

### 切ったところを戻す

**カット「非表示」**にすると、残っている素材だけが並びます。
その**端を切れ目のほうへドラッグ**すると、引いた分だけ切った素材が戻ります。
全部戻すと、そのカットは無くなります。

（編集ソフトで「切りすぎたので少し戻す」をするときと同じ操作です）

### 要らない場面を丸ごと切る

無音でもフィラーでもない箇所（脱線、失敗、雑音）も切れます。

1. 切りたいところの手前で **I**
2. 終わりのところで **O**
3. **Enter**

**Esc** で選び直せます。

### 間の詰め具合

何も選んでいないとき、右側に出ます。変えると候補を作り直します（数秒）。

| | どうなるか |
|---|---|
| ゆったり | 間を大きく残す。落ち着いた話し方向け |
| ふつう | 標準 |
| テンポよく | よく詰まる |
| とにかく詰める | 間がほとんど残らない |

**解析はやり直しません。** ただし、それまでに押した「切る／残す」はやり直しになります。

### 戻す

**Ctrl + Z**（Mac は ⌘Z）。何を戻したかが画面に出ます。

決まったら右上の **「テロップへ進む →」** を押します。

---

## 6. テロップを直す

カットした結果の文字起こしから、テロップを作ります。
**⚠ が付いているものだけ**見れば足りるように作ってあります
（上の **⚠ 要確認だけ** で絞り込めます）。

タイムラインの**テロップの帯**を押すか、**プレビューの文字を直接押す**と、右側で直せます。
重なっているときは、上に出ているほうが選ばれます。

| 項目 | |
|---|---|
| 文言 | 打ち直すと、改行も自動で計算し直します |
| 雛形 | **1〜9** の数字キーでも切り替わります |
| 出る時間 | **−1f / +1f**、または帯の端をドラッグ |
| 改行の位置 | 文字のあいだの **`·`** を押すとそこで改行（**`↵`** に変わります） |
| 目立たせる語 | その語だけ色を変えます |
| 位置 | **プレビューの文字をドラッグ** |

### コピー・貼り付け

| キー | |
|---|---|
| **Ctrl + C** | コピー |
| **Ctrl + V** | いまの**再生位置**に貼り付け |
| **Ctrl + D** | 複製（すぐ後ろに置く） |
| **Delete** | 消す |
| **Ctrl + Z** | ひとつ戻す |

Mac は Ctrl の代わりに **⌘** です。ボタンも右側にあります。

### 同じ時間に何枚でも出せます

重ねて置くと、**重ならないように段をずらして**出します。
下寄せのテロップなら上へ、上寄せなら下へずれます。

- タイムラインでも段が分かれて並ぶので、1枚ずつ選べます
- **選んでいるテロップには黄色い点線の枠**が出ます。どれを掴んでいるか分かります
- 動かしていると、**他のテロップと上下左右のラインが合う所で吸い付き**ます。
  合った所には水色の線が出ます。合わせたくないときは **Shift** を押しながら動かします
- タイムラインでも、**カットの切れ目と、他のテロップの端**に吸い付きます
- **画面で見えているとおりに書き出されます**（プレビューと書き出しは同じ絵を通っています）

### ここでカットも直せます

いちばん上の**素材**の段で、切る所が暗くなっています。端をドラッグすれば直せます
（「元の素材」の目盛りに切り替えてから）。

> **カットを変えても、テロップの文言はそのままです。**
> テロップは「カットした後の文字起こし」から作っているので、
> カットを広げると**切ったはずの言葉がテロップに残ります**。
> 変えたときは右側に **「テロップを今のカットで作り直す」** が出るので、押してください。
> 手で直した内容は引き継がれます。

### BGM

何も選んでいないとき、右側の **「♪ 音楽を追加」** から入れられます。
mp3 / m4a / wav などが使えます。

- 音量は声より小さめが既定です。**声の大きさは BGM に影響されません**
- 動画の長さに合わせて切り、終わりは自然に消えます。足りなければ繰り返します
- タイムラインの **BGM の帯**を掴むと、鳴り始める位置を動かせます

### 音がうるさいとき

再生の右にある**音量つまみ**で下げられます。🔉 を押すと消音です。
どの画面でも同じ場所にあります。

### 書体（フォント）を変える

右側の **「雛形「通常」を編集」** を開きます。**その枠を使っているテロップ全部**に効きます。

| | どんな字 |
|---|---|
| ゴシック体 | 標準。太くてはっきり読める |
| 丸ゴシック体 | 角が丸い。やわらかい印象 |
| 明朝体 | 縦横に太さの差がある。落ち着いた印象 |
| インパクト | 極太の見出し用。短い言葉向け |

**太字** と **斜体**、**色**、**縁の色**、**大きさ**、**置く場所**（上・中央・下）も同じ所です。

- 太字は、**その書体の太いほうの字に切り替わります**（無理に太らせているのではありません）。
  ただし「インパクト」だけは太さが1種類しか無いので、字を太らせて作ります
- 書体を変えると**改行の位置も計算し直します**。書体によって字の幅が違うためです

### 見た目に名前を付けて覚えておく

雛形をひととおり決めたら、何も選んでいない状態で **「＋ 今の見た目を保存」** を押して
名前を付けてください（例:「普段用」「商品紹介用」）。

- **次に別の動画を編集するとき、最後に使った組で始まります**
- 一覧の名前を押すと、その見た目が**今の動画にも当たります**
- 覚えるのは色・書体・太さ・大きさ・位置で、テロップの文言は覚えません

決まったら右上の **「書き出しへ進む →」** を押します。

## 7. 通しで確認して書き出す

カット・テロップ・BGM を**すべて乗せた状態**で通して再生できます。
ここで見えているものが、そのまま書き出されます。

### 書き出すもの

右側の3つのチェックで選びます。

| | 何が出るか |
|---|---|
| 動画に文字を入れる | テロップを焼き込んだ動画 |
| 字幕ファイル（.srt）も作る | 他の編集ソフトで読める字幕 |
| Final Cut 用（.fcpxml）も作る | **カットとテロップが入ったタイムライン** |

**Final Cut で仕上げたい場合**は、3つ目にチェックを入れてください。
Final Cut の「ファイル → 読み込む → XML…」から開くと、カットが入った状態になります。
テロップの**書体・色・大きさ・位置もそのまま入ります**。

#### 初回だけ、フォントを入れてください

このアプリのフォントは**アプリの中にしか入っていません**。
そのままだと、Final Cut は書体だけ別のもの（ヒラギノなど）に置き換えて開きます。
警告は出ません。

書き出したファイルの隣に **「〜_フォント」** というフォルダができています。

1. そのフォルダを開く
2. 中の **.ttf ファイルをすべて選んで**ダブルクリック
3. 出てきた窓の **「インストール」** を押す（Font Book が開きます）

**入れるのは最初の1回だけです。** 次の動画からは何もしなくて構いません。
色・大きさ・位置は、フォントを入れなくても合います。

### 書き出す

**「書き出す」** を押します。10分の動画で **3〜8分** くらいかかります。
進み具合と残り時間が出ます。途中でやめることもできます。

## 困ったとき

### 途中でやめたい

**「編集をやめる」** を押すと、下書きを保存するか聞かれます。
保存しておけば、次に同じ動画を開いたとき**続きから始められます**（解析もやり直しません）。

アプリの最初の画面にも「途中の編集を続ける」として並びます。

### 「この動画は編集できません」と出た

声が入っていない動画です。このアプリは話している内容をもとに編集するので、
声が入っていないと何もできません。

### エラーが出た

メニューの **「ヘルプ → 不具合の記録を開く」** を押すと、
記録のあるフォルダが開き、**`last-error.json` が選ばれた状態**になります。

送ってほしいのは次の2つです。

| ファイル | 中身 |
|---|---|
| `last-error.json` | 何をしようとして失敗したか |
| `sidecar-error.json` | 動画を扱う部品が実際に何と言ったか |

`last-launch.json` は起動しただけの記録なので、原因は入っていません。

**画面に出た文言もそのまま教えてください。** 「詳しい理由:」の行に、
本当の原因が1行で出ています。

### 動作が重い

- 電源につないでください
- 他のアプリを閉じてください
- 20分を超える動画は時間がかかります。まずは10分くらいで試してください

### キーボード操作を忘れた

**F1** を押すと一覧が出ます。
